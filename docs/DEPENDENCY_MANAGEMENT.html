1. Hosting & Infrastructure Architecture

Architecture Philosophy: OyeChats uses a hybrid cloud model designed for ultra-low fixed operating costs (~$12/month). Core backend APIs, vector database, and background task processing run on a dedicated DigitalOcean droplet, while frontend sub-apps are hosted on Vercel's global edge CDN, and chat widget IIFE scripts are served globally from Cloudflare R2 CDN.
